## Claim boundary and completion record

The fresh hosted `full` Evidence Capsule must identify the exact candidate,
specification, plan, generator, profile, provider, corpus, validators, toolchain,
JVM, platform, and protocol, and give one retained result for every selected
scenario. Its traceability must include all in-scope deviations, both profile
modes, applicable decode and encode differentials, Independent Validators,
malformed and resource limits, filesystem safety, cancellation, rollback,
sequential/parallel equivalence, and deterministic output. Missing, stale,
foreign, contradictory, or unavailable required evidence is `INVALID` under
[JBSA-ASR-002/003/006](../../../spec/assurance-v2.md). Binary Conformance is a
separate optional case claim; manual game/official-tool Release Qualification is
separate and is not included here.

the [Assurance v2 migration record](../../../../tests/assurance/migration.md).
It must not be described as shipping-compatible or counted as a passing
selected scenario. The Xbox DDS deferral above is the only first-release feature
deferral in [JBSA-SCOPE-009](../../../spec/scope.md#jbsa-scope-009).
